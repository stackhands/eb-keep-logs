* JSON output schemas

The Zig build's =--json= on =why=, =history=, =failures=, =loads=, =runs=, =used=, =usage=, =pending=, =test-compare= and =lifecycle= prints one line of JSON with =schema_version= 1.
The =test-bundle= command always writes one JSON document with =schema_version= 1.
The shell script refuses those commands; see [[file:compatibility.org][Compatibility]].
Each document is validated in CI against a JSON Schema file in the repository tree under =docs/orgmode/reference/json/=.
The schemas use draft 2020-12; a new =schema_version= may drop or rename a key, or change what one means.

| Command  | Schema file in the repository |
|----------+-------------------------------|
| =why=    | =docs/orgmode/reference/json/why.schema.json= |
| =history= | =docs/orgmode/reference/json/history.schema.json= |
| =failures= | =docs/orgmode/reference/json/failures.schema.json= |
| =loads=  | =docs/orgmode/reference/json/loads.schema.json= |
| =runs=   | =docs/orgmode/reference/json/runs.schema.json= |
| =used=   | =docs/orgmode/reference/json/used.schema.json= |
| =usage=     | =docs/orgmode/reference/json/usage.schema.json= |
| =pending=   | =docs/orgmode/reference/json/pending.schema.json= |
| =test-bundle= | =docs/orgmode/reference/json/test-bundle.schema.json= |
| =test-compare= | =docs/orgmode/reference/json/test-compare.schema.json= |
| =lifecycle= | =docs/orgmode/reference/json/lifecycle.schema.json= |

Field names and semantics for =why=, =history=, =failures=, =used=, =usage= and =lifecycle= are under [[file:cli.org][The eb-keep-logs command]].
=loads=, =runs=, =pending=, =test-bundle= and =test-compare= document their JSON shape in the same page.
