* The eb-keep-logs command

=eb-keep-logs= keeps the logs of a failed EasyBuild build, compresses and removes the old runs of a log tree, says from the kept logs why a run's builds failed, lists how a package's builds went run by run, lists failed builds across runs filtered by recipe or date, reads who loaded a module from Lmod's usage log, reads who ran an executable from an XALT run record, lists paths under an install prefix from those records, classifies installed software by its recorded use, reads what an EasyBuild dry-run or missing-modules report still has to build, writes a flaky-test evidence bundle, and compares such bundles across sites.
This page describes the Zig build; the shell script =eb-keep-logs= in the repository behaves the same, except as [[file:compatibility.org][Compatibility]] lists: it has no =why=, =history=, =failures=, =loads=, =runs=, =used=, =usage= or =pending=.

** Synopsis

#+begin_example
eb-keep-logs failed [--syslog TARGET] [--metrics-file PATH] STATUS NAME LOGDIR [TMP_LOGDIR]
eb-keep-logs rotate ROOT --compress-after DAYS [--delete-after DAYS] [--dry-run] [--lock-timeout SECONDS] [--syslog TARGET] [--metrics-file PATH]
eb-keep-logs why [RUN | --latest] [--target TARGET] [--package PACKAGE] [--since DATE] [--until DATE] [--root ROOT] [--json]
eb-keep-logs history PACKAGE [--target TARGET] [--since DATE] [--until DATE] [--failed] [--root ROOT] [--json]
eb-keep-logs failures [--package PACKAGE] [--target TARGET] [--since DATE] [--until DATE] [--root ROOT] [--json]
eb-keep-logs loads --module NAME [--json] FILE
eb-keep-logs runs --exec PATH [--json] FILE
eb-keep-logs used --prefix PREFIX [--json] [--require-none] FILE...
eb-keep-logs usage --software DIR --modules DIR [--since EPOCH] [--unused | --active] [--json] FILE...
eb-keep-logs pending [--json] FILE
eb-keep-logs test-bundle --test-id ID --suite-revision REV --eessi-target TARGET --stdout FILE --stderr FILE [--input FILE ...] [--module NAME=PATH ...] --seed SEED --allocation TEXT --binding TEXT --cpu TEXT --gpu TEXT [--out FILE]
eb-keep-logs test-compare [--json] BUNDLE...
eb-keep-logs -h | --help
eb-keep-logs --version
#+end_example

** Arguments

| Argument     | Command  | Meaning                                                                                                                                                                                                 |
|--------------+----------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =STATUS=     | =failed= | The exit status =eb= returned, in decimal digits. A status of only zeros keeps and changes nothing, once =LOGDIR= has been checked.                                                                     |
| =NAME=       | =failed= | The easyconfig's name without =.eb=, as in =LOGDIR/NAME.stdout.log=; it names the copies, and without =TMP_LOGDIR= it tells the build's own log from another build's.                                   |
| =LOGDIR=     | =failed= | The run's directory, which holds =NAME.stdout.log= and gets the copies and =.licensed-logs=; a symbolic link to a directory is followed.                                                                |
| =TMP_LOGDIR= | =failed= | The =--tmp-logdir= =eb= ran with, passed on to =eb --last-log=. Empty is the same as not given: =eb --last-log= then names the newest log in EasyBuild's default place. Arguments after it are ignored. |
| =ROOT=       | =rotate= | The directory that holds the runs. A run is a directory directly under it, not a symbolic link, named =YYYYMMDD_HHMMSS= with a date that exists; everything else under it is left alone.                |
| =RUN=        | =why=    | The run to read: a path, or a name under =--root=. Its builds are in it, as =failed= given it as =LOGDIR= keeps them, or in its directories, one per target, not symbolic links, as eb-pipeline keeps them. |
| =PACKAGE=    | =history= | An easyconfig's name, or its start up to a dash: =hello= and =hello-2.12.1= both take =hello-2.12.1-GCCcore-14.2.0=, and =hello= takes =hello-world-1.0= too. A module name, =hello/2.12.1=, is read as =hello-2.12.1=. |

- A run's age is the number of whole days from the local midnight of the date in its name; [[file:../explanation/local-time.org][Run ages and local time]] gives the details.
- =--dry-run= reads the tree and the processes writing into it without taking the rotation lock, so its output is a snapshot, not a reservation. It also skips syslog emission and =--metrics-file= updates.
- =rotate='s options and =ROOT= come in any order; the value of an option is the next argument, whatever it is.
  An option given twice takes its last value.
- =why='s options and =RUN=, and =history='s and =PACKAGE=, come in any order, and an option given twice takes its last value; the value of an option is the next argument, whatever it is, and an empty one is refused.
- =-h=, =--help= and =--version= count only in the place of the command.
- =failed='s options and positional arguments may appear in any order.
- What =why=, =history=, =failures=, =loads=, =runs=, =used=, =usage= and =pending= print, and the =--policy= path in =lifecycle --json=, is UTF-8: a byte that is not part of a UTF-8 character, whether from a log, a record, a directory name or the command line, is printed as U+FFFD, and its =--json= field stays a string.
  Names and paths are matched and counted by their bytes as given, before that replacement: =--module=, =--exec=, =--prefix=, =--software= and =--modules= match a record or a directory with the same bytes, and two names that differ only in such a byte stay two entries, though they print alike.

** Files

*** failed

| File                                             | Use                                                                                                                                                                                                      |
|--------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =LOGDIR/NAME.stdout.log=                         | Read: the last =.../run-shell-cmd-output/DIR/out.txt= path in it names the failed command's output. Closed to others, not through a symbolic link.                                                       |
| the session log =eb --last-log= names            | Read, and copied to =LOGDIR/NAME.failed.ebout.log=. When =NAME.stdout.log= names no =out.txt=, the last one the session log names is taken, unless the log records that command completing successfully. |
| =LOGDIR/NAME.failed.ebout.log=                   | The session log.                                                                                                                                                                                         |
| =LOGDIR/NAME.failed.command-out.txt=, =-err.txt= | The failed command's =out.txt= and, when there is one, =err.txt=, mode 0600. A stream that is a symbolic link is not opened.                                                                             |
| =LOGDIR/NAME.failed.meson-testlog.txt=           | =meson-logs/testlog.txt= of the last =meson test -C DIR= the session log names, unless every test in it passed.                                                                                          |
| =LOGDIR/.licensed-logs=                          | Each copy's absolute path, with symbolic links resolved, is appended unless the list has it.                                                                                                             |
| =TMP_LOGDIR=                                     | Closed to others, with the regular files directly in it, when it lies below =LOGDIR=.                                                                                                                    |

Each copy is written to a temporary file in =LOGDIR= and renamed over the name, so a copy that fails part way leaves an earlier one as it was.
A copy takes the source's mode, or the mode and, when permitted, the owner of the file it replaces, without others' bits; the command's streams are mode 0600.
A symbolic link, a directory or another file that is not a regular one at a copy's name is not written through: the copy is refused, with =eb-keep-logs: cannot keep LOGDIR/FILE: ERROR= on stderr.

| =Failed command output: LOGDIR/NAME.failed.command-out.txt=           | A command stream was kept, one line for each.                                                                              |
| =Failed meson test log: LOGDIR/NAME.failed.meson-testlog.txt=         | The meson test log was kept.                                                                                               |
| =No EasyBuild log to keep for NAME: eb is not on PATH.=               | =eb= is not on =PATH=; nothing is kept.                                                                                    |
| =No EasyBuild log to keep for NAME: eb --last-log exited N.=          | =eb --last-log= failed; nothing is kept.                                                                                   |
| =No EasyBuild log to keep for NAME.=                                  | =eb --last-log= printed nothing, named no log that could be opened, or did not return within 300 seconds; nothing is kept. |
| =No EasyBuild log to keep for NAME: PATH is another build's log.=     | Without =TMP_LOGDIR=, the newest log is another build's; the command output =NAME.stdout.log= names is still kept.         |

*** rotate

| File                                | Use                                                                                                                                                                                                                                                     |
|-------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =ROOT/.eb-keep-logs-rotate.lock=    | Created empty when missing, and left in place. =rotate= holds an exclusive flock(2) lock on it from before it lists =ROOT= until it exits, and opens it for reading when it may not write it. eb-pipeline's =ROOT/.eb-pipeline-rotate.lock= is another lock, which =rotate= does not take. |
| =ROOT/RUN/.../FILE.log=, =FILE.txt= | In a run old enough, replaced by =FILE.gz= with the file's mode, as =gzip -9= does; a symbolic link is not followed, and a file with other hard links or an existing =FILE.gz= is left as it is, with a message on stderr.                              |
| =ROOT/RUN/.../.licensed-logs=       | In a run in which files were compressed, a line that names one of them, by its absolute path with symbolic links resolved, is changed to name its =.gz= file. A list that changes keeps its owner when permitted, its mode and its access control list. It is replaced whole: the new list is written to a file beside it, synced and renamed over it, and the directory is synced, so a reader finds the old list or the new one, never part of one. |
| =ROOT/RUN=                          | Removed with everything in it, when old enough for =--delete-after=, without being compressed first. A symbolic link in it is removed, not followed. Removal stops at the first error.                                                                  |
| =/proc/PID/fd/N=                    | Read, for every process whose descriptors =rotate= may read, after it has the lock: a link with its owner's write bit names a file the process has open for writing, and the run that file is in is left alone. Without =/proc=, no run is left alone for it. |

With =--dry-run= these paths are only read; =ROOT/.eb-keep-logs-rotate.lock= is neither opened nor created, =--metrics-file= neither reads nor writes any metrics or lock file, and files that already have a =.gz= sibling or other hard links are skipped as =rotate= skips them.

A run that holds the file =rotate='s standard output or standard error goes to, or =EB_PIPELINE_LOG_DIR=, or a file another process has open for writing, as a build that is still going has its log, is left alone, neither compressed nor deleted; a later =rotate= takes it.
The path is what counts: the path the link in =/proc= names, or for a file removed since, that path with =" (deleted)"= after it, has to start with =ROOT='s, with symbolic links resolved.
On stdout =rotate= prints one line, with =ROOT= as given:

#+begin_example
eb-keep-logs rotate: N files compressed, M runs deleted under ROOT
#+end_example

with =1 file= and =1 run= for a count of one.
What =rotate= cannot do it reports on stderr as =eb-keep-logs: MESSAGE=, and goes on with the rest; a file or run it reports is not counted:

| =MESSAGE=                               | Cause                                                                                                                               |
|-----------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------|
| =cannot lock ROOT/.eb-keep-logs-rotate.lock: ERROR; rotating without the lock= | The file system cannot take the lock, or not for this user: =Unsupported= where it takes no locks, =InvalidArgument= on NFS for a lock file open only for reading, =Unexpected= when no lock is available (=ENOLCK=). =rotate= goes on without it. |
| =cannot compress PATH: ERROR=           | =PATH= is left as it is: it has other hard links (=TooManyLinks=), =PATH.gz= exists (=Exists=), or it could not be read or written. |
| =cannot open PATH: ERROR=               | A run, or a directory in a run, could not be opened; nothing in it is compressed.                                                   |
| =cannot read PATH: ERROR=               | Listing a run, or a directory in it, failed part way; nothing in it is compressed.                                                  |
| =cannot resolve a run directory: ERROR= | The absolute path of a run, or of a directory in it, could not be found; nothing in it is compressed.                               |
| =cannot read a .licensed-logs: ERROR=   | A list could not be read, or is larger than 64 MiB; it is left as it is.                                                            |
| =cannot update a .licensed-logs: ERROR= | A list could not be replaced; it is left as it is.                                                                                  |
| =cannot sync a .licensed-logs: ERROR=   | A list was replaced, but its directory could not be synced; after a crash the old list may be back.                                 |
| =cannot delete ROOT/RUN: ERROR=         | The run could not be removed completely; what was removed stays removed.                                                            |

*** Metrics

With =--metrics-file PATH=, =failed= and =rotate= update one Prometheus text exposition file.
When =--dry-run= is given to =rotate=, it writes no metrics and leaves any existing metrics file and its sidecar lock untouched.
The file is written to a temporary file in =PATH='s directory, synced, and renamed over =PATH= while a sidecar lock is held.
An existing valid file supplies the counters and timestamp that the other command owns.
An invalid file is left unchanged and reported on stderr.

| Metric | Type | Value |
|--------+------+-------|
| =eb_keep_logs_logs_kept_total= | counter | Successful log-copy operations by =failed=, including a retry that copies the same destination again. |
| =eb_keep_logs_bytes_kept_total= | counter | Bytes in those successfully written copies. |
| =eb_keep_logs_last_prune_timestamp_seconds= | gauge | Actual Unix timestamp when =rotate= most recently completed (excluding =--dry-run=), including a rotation that found nothing to change. It is chosen under the metrics lock, never moves backwards when rotations complete out of order, is independent of =EB_KEEP_LOGS_NOW=, and is zero until one completes. |

Metrics are values this tool observes while keeping and rotating logs.
They do not describe dependency gaps, rebuild closures, failure classes, or other stack analysis.
See [[file:../howto/export-prometheus-metrics.org][Export metrics to Prometheus]] for the node_exporter textfile collector setup.

*** why

=why= only reads.
A build is a =NAME= with either of its logs in the run's own directory or in one of its target directories; of =FILE= and =FILE.gz=, =FILE= is read, and a =.gz= file is read through gzip, its CRC-32 checked.

| File                                        | Use                                                                                                                                                                                                                                              |
|---------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =RUN/[TARGET/]NAME.stdout.log=, =.gz=       | EasyBuild's output, which says how the build went: the last =COMPLETED: Installation ended successfully= or =FAILED: Installation ended unsuccessfully= in it decides, with the duration in it; an =ERROR:= line after a success, or without either, is a failure. |
| =RUN/[TARGET/]NAME.failed.ebout.log=, =.gz= | The session log =failed= kept, which says why the build failed. A build whose output says nothing of how it went has failed when this log is there; without either, its outcome is unknown.                                                    |

What =why= takes from a failed build's session log, or from its output when it has none:

| Item       | Taken from                                                                                                                                                                                                                                                                                                                                                         |
|------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| package    | EasyBuild's =building and installing NAME/VERSION...=.                                                                                                                                                                                                                                                                                                              |
| easyconfig | EasyBuild's =processing EasyBuild easyconfig PATH=.                                                                                                                                                                                                                                                                                                                 |
| message    | EasyBuild's message for the failure: =EasyBuild encountered an error: MESSAGE= in the session log; in the output, the =FAILED: Installation ended unsuccessfully: MESSAGE= entry with EasyBuild's wrapping at 80 columns undone, or else the first =ERROR: MESSAGE=. Its first 400 bytes.                                                                    |
| step       | The step the =FAILED= entry names, as in =... failed with exit code 2 in build step for NAME.eb=; else the last step the log shows starting before the failure: =Starting STEP step= in the session log, an announcement such as ~== sanity checking...~ in the output. By EasyBuild's name, as =eb --stop= takes it: =fetch=, =ready=, =extract=, =patch=, =prepare=, =configure=, =build=, =test=, =install=, =extensions=, =postiter=, =postproc=, =sanitycheck=, =cleanup=, =module=, =permissions=, =package=, =testcases=. None when the failure came before the first step, as a missing dependency does. |
| error      | The line that shows the error: the first compiler or linker error from the start of that step to EasyBuild's own error line, else that line. A compiler's error is one at a source line, =FILE:LINE: error:= or =FILE:LINE:COLUMN: fatal error:= as GCC and Clang print it, or =FILE(LINE): error:= as nvcc does; a linker's is =undefined reference to= or =cannot find -l= as GNU ld prints them, or =undefined symbol:= as lld and mold do. EasyBuild's own error line is its first =EasyBuild encountered an error= in the session log; in the output, the =FAILED= entry, or else the first =ERROR:=. In a session log, nothing before the first step counts. With its line number and three lines either side, each cut to 400 bytes. |
| duration   | The =(took DURATION)= of the =FAILED= entry, in seconds.                                                                                                                                                                                                                                                                                                         |

*** history

=history= only reads, the same files as =why=: in each run under =ROOT=, oldest first, in the run's own directory and then in each of its target directories, by name, the builds whose =NAME= is =PACKAGE= or starts with =PACKAGE= and a dash.

With =--json=, =history= prints one line of JSON instead, its keys in this order:

| Key              | Value                                                                                                  |

*** failures

=failures= only reads, scanning the runs under =ROOT= oldest first and filtering by =--since=, =--until=, =--target= and =--package=.
For each failed build it reads the kept session log (or =NAME.stdout.log= when no session log exists) to report the failed EasyBuild step and duration:

** loads

=loads --module NAME [--json] FILE= prints who loaded =NAME=, from Lmod's ModuleUsageTracking lines in =FILE=.
A record is =user=USER module=NAME path=PATH host=HOST time=TIME=, in any order, with a syslog prefix left in place.
Each load is one line, =user=USER host=HOST time=TIME path=PATH=, in the file's order.
A file with no load of =NAME= prints =no load of NAME=; with =--json= the =loads= array is empty.
A line that is not a record is skipped.
The shell script has no =loads=.

With =--json= the document has =schema_version= 1, =kind= ="loads"=, =module=, and a =loads= array in file order. Each element has =user=, =host=, =time= and =path= as the text lines print them.

| Argument | Meaning |
|---|---|
| =NAME= | The module's full name, as Lmod recorded it, such as =GROMACS/2024.1=. Required, as =--module NAME= or =--module=NAME=. |
| =--json= | Print one line of JSON instead of the text lines. |
| =FILE= | The log. A file that cannot be read is refused. |


** used

=used --prefix PREFIX [--json] [--require-none] FILE...= lists paths under =PREFIX= that appear in XALT or Lmod records in =FILE=.
A path is under =PREFIX= when it equals it or starts with =PREFIX/= after trimming a trailing slash from =PREFIX=.
A run record contributes =userT.exec_path= as kind =run= and each =libA= path under =PREFIX= as =run-lib=, even when =exec_path= is outside.
A link record contributes =resultT.exec_path= and each =linkA= library path as =link=.
A package record contributes =package_path= as =pkg=.
An Lmod tracking line contributes =path= as =module-load= when it is under =PREFIX=.
Each distinct =path= and kind is one line, =path=PATH kind=KIND last=TIME count=N=; =last= is the newest time seen for that path and may be empty.
No hit prints =nothing under PREFIX= on stdout.
=--json= prints one JSON document with =schema_version= 1, =prefix=, and a =uses= array of ={kind, path, last, count}= objects.
=--require-none= exits 2 when any path was listed; with no hit it exits 0.
The shell script has no =used=.

| Option / argument | Meaning |
|---|---|
| =PREFIX= | The install tree. Required, as =--prefix PREFIX= or =--prefix=PREFIX=. A newline in it is refused. |
| =--json= | Print one line of JSON instead of the text lines. |
| =--require-none= | Exit 2 when any path under =PREFIX= was found. |
| =FILE= | One or more record files. Concatenated XALT JSON objects and/or Lmod lines. A file that cannot be read, or truncated JSON, is refused. |

** usage

=usage --software DIR --modules DIR [--since EPOCH] [--unused | --active] [--json] FILE...= compares the installed software below =DIR= with XALT and Lmod records.
An installed entry is each directory =DIR/Name/Version=.
An XALT run, run-library, link, link-library or package path below the software directory is a hit on the =Name/Version= in its first two path components.
An Lmod ModuleUsageTracking record is a hit on its =module=NAME/Version= when its =path= is below the modules directory.
Records from all =FILE= arguments are parsed once, in command-line order, and their hits are combined.

Without a selection option, text output is sorted by =Name/Version= and has one of these forms:

#+begin_example
active Name/Version hits=N last=EPOCH
unused Name/Version
#+end_example

=last= is the newest textual time in a hit and is empty when the newest hit did not spell its time as a string.
=--unused= prints only installed entries with no hit, one =Name/Version= per line, for review as retirement or uninstall candidates.
=--active= prints only entries with a hit in the same one-per-line format.
That active listing is a module listing accepted directly by =eb-stack stack gap --site=; =usage= does not classify gaps or replace that command.
=--unused= and =--active= are mutually exclusive.

=--since EPOCH= counts a record only when its numeric time is at least =EPOCH=.
It therefore leaves out XALT package records and other records without a time.
Epoch values may include a fractional part and must be finite and non-negative.

With =--json= the document has =schema_version= 1, =kind= ="usage"=, =software=, =modules=, =since= (the argument as text or =null=), =selection= (="all"=, ="unused"= or ="active"=), and a sorted =packages= array.
Each package has =name=, =version=, =module=, =active=, =hits= and =last= (a time string or =null=).
The selection filters the JSON array as it filters text.
The shell script has no =usage=.

| Option / argument | Meaning |
|---|---|
| =--software DIR= | The software install tree. Required. |
| =--modules DIR= | The module tree used to constrain Lmod record paths. Required. |
| =--since EPOCH= | Count timed records at or after =EPOCH=. |
| =--unused= | List installed entries with no hit. |
| =--active= | List installed entries with at least one hit. |
| =--json= | Print one JSON document instead of text. |
| =FILE= | One or more concatenated-XALT-JSON or Lmod usage-log files. Unreadable files, truncated JSON, or files containing neither JSON objects nor Lmod records are refused. |


** lifecycle

=lifecycle --policy FILE [--modulerc-out FILE] [--easyconfigs DIR ...] [--easystack FILE ...] [--eb-stack PATH] [--rebuild-set FILE] [--now EPOCH] [--json] FILE= turns a =usage --json= report (generated with =selection= ="all"=) and a TOML policy into a reviewable deprecation plan and Lmod =.modulerc.lua= warnings and forbids.
It never deletes software or modulefiles.

The TOML policy accepts an optional =[policy]= or =[lifecycle]= header and these keys:

- =min_observation_days= (required, integer >= 1): minimum span in days between =since= in the usage report and =now= before =candidate-remove= is permitted.
- =warn_after_days= (required, integer >= 0): idle age threshold for =warn=.
- =forbid_after_days= (required, integer >= =warn_after_days=): idle age threshold for =forbid-after=.
- =remove_after_days= (required, integer >= =forbid_after_days=): idle age threshold for =candidate-remove=.
- =forbid_grace_days= (optional, default 30): days added after =now= (or after reaching =forbid_after_days=) when computing the =after= date in Lmod =forbid{}= entries.
- =min_hits= (optional, default 1): minimum recorded hits required to treat an undated active hit as active.
- =keep= (optional, array of strings): module names or =*= / =?= glob patterns (such as ="GCCcore/*"=) that stay =keep=.
- =warn_message= and =forbid_message= (optional strings): templates supporting ={module}= and ={after}= placeholders for generated Lmod messages.

Before allowing =candidate-remove=, =lifecycle= enforces two guards:

1. The usage report must carry a numeric =since= covering at least =min_observation_days= up to =now=.
2. Installed reverse dependents must be checked with =eb-stack rebuild-set= (via =--easyconfigs=, or a precomputed =--rebuild-set= report). Any candidate absent from the easyconfig graph or with installed dependents is held back from =candidate-remove=; candidates with installed dependents are held at =warn= without emitting a =forbid= directive so dependent modules continue to load.

Without =--json=, text output prints one sorted line per installed module:

#+begin_example
ACTION Name/Version hits=N idle_days=D [forbid_after=YYYY-MM-DD] [dependents=M1,M2] reason="..."
#+end_example

With =--json=, the document has =schema_version= 1, =kind= ="lifecycle"=, =software=, =modules=, =policy=, =now=, =since=, =observed_days=, =min_observation_days=, =observation_satisfied=, =dependents_checked=, =counts= (with keys =keep=, =warn=, =forbid-after=, =candidate-remove=), =entries= and =modulerc_lua=.
With =--modulerc-out FILE=, the generated =.modulerc.lua= text is written atomically via a temporary file in the destination directory; symlinks and directories at =FILE= are refused.
The shell script has no =lifecycle=.

| Option / argument | Meaning |
|---|---|
| =--policy FILE= | TOML policy file. Required. |
| =--modulerc-out FILE= | Write generated =.modulerc.lua= warnings and forbids to =FILE=. |
| =--easyconfigs DIR= | Easyconfig tree passed to =eb-stack rebuild-set=. Repeatable. |
| =--easystack FILE= | Deployed easystack YAML passed to =eb-stack rebuild-set=. Repeatable. |
| =--eb-stack PATH= | Explicit path to =eb-stack=. Default: =eb-stack= on =PATH=. |
| =--rebuild-set FILE= | Precomputed =rebuild-set.json= from =eb-stack rebuild-set=. Mutually exclusive with =--easyconfigs=. |
| =--now EPOCH= | Reference epoch time in seconds. Default: =EB_KEEP_LOGS_NOW=, else current time. |
| =--json= | Print one JSON document instead of text. |
| =FILE= | JSON output from =eb-keep-logs usage --json= with =selection= ="all"=. Required. |


** runs

=runs --exec PATH [--json] FILE= prints who ran =PATH=, from XALT run records in =FILE=.
A run record is a JSON object whose =userT= holds =user=, =exec_path= and, when present, =syshost= and =start_time=.
A link record is not a run and is skipped.
=PATH= matches =exec_path= in full or as its last component.
Each run is one line, =user=USER host=HOST time=TIME path=PATH=, in the file's order.
A file with no run of =PATH= prints =no run of PATH=; with =--json= the =runs= array is empty.
The shell script has no =runs=. It does not record runs.

With =--json= the document has =schema_version= 1, =kind= ="runs"=, =exec= as given, and a =runs= array in file order. Each element has =user=, =host=, =time= and =path= as the text lines print them; fields XALT omitted are empty strings.

| Argument | Meaning |
|---|---|
| =PATH= | The executable, as a full path or its last component. Required, as =--exec PATH= or =--exec=PATH=. |
| =--json= | Print one line of JSON instead of the text lines. |
| =FILE= | One or more JSON objects. An object that is not a run record is skipped. A file that cannot be read, or that is not JSON, is refused. |


** pending

=pending [--json] FILE= prints what an EasyBuild dry-run or missing-modules report still has to build.
A dry-run line is =* [ ] PATH (module: NAME)=, and =[F]= and =[R]= still build. =[x]= is already installed and is not printed.
=--terse= prints =x PATH= or =- PATH=.
A missing-modules line is =* NAME (FILE.eb)=, or with =--terse= one easyconfig path on each line.
Each is one line, =build NAME= or =missing NAME=, in the file's order.
A report with nothing left prints =nothing to build=; with =--json= the =entries= array is empty.
The shell script has no =pending=. It does not run =eb=, and it does not resolve dependencies.

With =--json= the document has =schema_version= 1, =kind= ="pending"=, and an =entries= array in file order. Each element has =action= (="build"= or ="missing"=) and =name= as the text lines print them.

| Argument | Meaning |
|---|---|
| =--json= | Print one line of JSON instead of the text lines. |
| =FILE= | The report, as =eb --dry-run= or =eb --missing-modules= printed it. A file that cannot be read, or that is neither report, is refused. |

** test-bundle

=test-bundle= records one test run as a stable flaky-test evidence bundle.
It normalizes stdout and stderr to LF line endings, trims trailing spaces and tabs on each line, and ensures a trailing newline when there is output.
It hashes those normalized streams, hashes each =--input= file, hashes =--seed=, and records modules with modulefile paths, EESSI target, scheduler allocation and binding, CPU and GPU facts, and suite revision.
With =--out FILE= it writes JSON there; without it, it prints the JSON.
The JSON shape is schema_version 1 in [[file:json-schemas.org][JSON schemas]].

** test-compare

=test-compare= reads two or more =test-bundle= JSON documents and reports only which fields differ.
It does not decide pass or fail.
Compared fields are: test identity, suite revision, EESSI target, normalized stdout/stderr hashes, input and seed hashes, module list and paths, scheduler allocation and binding, and CPU/GPU facts.
With =--json= it prints schema_version 1 JSON; without it, a text summary.

          While another rotate holds the lock, wait up to SECONDS for it,
          then give up and exit 75. Default: 600; 0 does not wait. An empty
          value is the default.
      --syslog TARGET, --syslog=TARGET
          Emit an RFC 5424 or native systemd-journald event with the
          compressed and deleted counts. Default: EB_KEEP_LOGS_SYSLOG,
          else none.
      --metrics-file PATH, --metrics-file=PATH
          Atomically record when this rotation completed, unless --dry-run
          is given. Default: none.
  eb-keep-logs why [RUN | --latest] [--target TARGET] [--package PACKAGE]
                   [--since DATE] [--until DATE] [--root ROOT] [--json]
      Say why the builds of a run failed: for each failed easyconfig, its
      package and easyconfig, the EasyBuild step it failed in, EasyBuild's
      message, and the line of its kept log that shows the error: the first
      compiler or linker error, else EasyBuild's own error line, with the
      line number and three lines either side. Logs rotate compressed are
      read as they are. Zig build only. RUN and the options come in any
      order.
      RUN
          A run directory, as a path or as a name under ROOT.
      --latest
          The newest run under ROOT, or the newest with a directory
          TARGET. The default when no RUN is given.
      --target TARGET, --target=TARGET
          Only the builds in the run's directory TARGET. Default: those in
          the run's own directory and in every directory in it.
      --package PACKAGE, --package=PACKAGE
          Only builds matching PACKAGE (an easyconfig name without .eb,
          a prefix up to a dash, or NAME/VERSION). Default: all builds.
      --since DATE, --since=DATE
          Only consider runs at or after DATE when picking --latest.
          DATE is YYYY-MM-DD, YYYYMMDD, or YYYYMMDD_HHMMSS.
          Default: none.
      --until DATE, --until=DATE
          Only consider runs at or before DATE when picking --latest.
          DATE is YYYY-MM-DD, YYYYMMDD, or YYYYMMDD_HHMMSS.
          Default: none.
      --root ROOT, --root=ROOT
          The directory that holds the runs. Default: the current
          directory.
      --json
          Print one line of JSON instead, with schema_version 1.
  eb-keep-logs history PACKAGE [--target TARGET] [--since DATE]
                       [--until DATE] [--failed] [--root ROOT] [--json]
      Say how each kept build of PACKAGE went, oldest run first: success,
      failed or unknown, and how long EasyBuild took, from its output.
      PACKAGE is an easyconfig's name or its start up to a dash, as hello
      or hello-2.12.1 for hello-2.12.1-GCCcore-14.2.0, or a module name, as
      hello/2.12.1; hello also takes hello-world-1.0. Zig build only.
      PACKAGE and the options come in any order.
      --target TARGET, --target=TARGET
          Only the builds in each run's directory TARGET. Default: those in
          each run's own directory and in every directory in it.
      --since DATE, --since=DATE
          Only read runs at or after DATE (YYYY-MM-DD, YYYYMMDD, or
          YYYYMMDD_HHMMSS). Default: none.
      --until DATE, --until=DATE
          Only read runs at or before DATE (YYYY-MM-DD, YYYYMMDD, or
          YYYYMMDD_HHMMSS). Default: none.
      --failed
          Only list failed builds.
      --root ROOT, --root=ROOT
          The directory that holds the runs. Default: the current
          directory.
      --json
          Print one line of JSON instead, with schema_version 1.
  eb-keep-logs failures [--package PACKAGE] [--target TARGET]
                        [--since DATE] [--until DATE] [--root ROOT] [--json]
      List failed builds across runs under --root, oldest run first.
      Each row gives the run, target, failed step, duration and build
      name. Zig build only. Options come in any order.
      --package PACKAGE, --package=PACKAGE
          Only failed builds matching PACKAGE (an easyconfig name
          without .eb, a prefix up to a dash, or NAME/VERSION). Default:
          all packages.
      --target TARGET, --target=TARGET
          Only the builds in each run's directory TARGET. Default: those
          in each run's own directory and in every directory in it.
      --since DATE, --since=DATE
          Only read runs at or after DATE (YYYY-MM-DD, YYYYMMDD, or
          YYYYMMDD_HHMMSS). Default: none.
      --until DATE, --until=DATE
          Only read runs at or before DATE (YYYY-MM-DD, YYYYMMDD, or
          YYYYMMDD_HHMMSS). Default: none.
      --root ROOT, --root=ROOT
          The directory that holds the runs. Default: the current
          directory.
      --json
          Print one line of JSON instead, with schema_version 1.
  eb-keep-logs loads --module NAME [--json] FILE
      Print who loaded NAME, from Lmod's ModuleUsageTracking lines in FILE.
      Each record is user=USER module=NAME path=PATH host=HOST time=TIME,
      in any order, and a syslog prefix is left in place. Each load is
      one line, user=USER host=HOST time=TIME path=PATH, in the file's
      order. A file with no load of NAME prints no load of NAME. Zig
      build only.
      --module NAME, --module=NAME
          The module's full name, as Lmod recorded it, such as
          GROMACS/2024.1. Required.
      --json
          Print one line of JSON instead, with schema_version 1.
      FILE
          The log that holds the records. A line that is not one is
          skipped.
  eb-keep-logs used --prefix PREFIX [--json] [--require-none] FILE...
      Print paths under PREFIX that appear in XALT or Lmod records in
      FILE. A run record lists userT.exec_path (kind run) and each libA
      path under PREFIX (kind run-lib) even when exec_path is outside.
      A link record lists resultT.exec_path and each linkA path (kind
      link). A package record lists package_path (kind pkg). An Lmod
      tracking line lists path when it is under PREFIX (kind module-load).
      Each line is path=PATH kind=KIND last=TIME count=N; last is the
      newest time seen for that path. With no hit, nothing under PREFIX.
      --json prints one JSON document with schema_version 1. --require-none
      exits 2 when any hit is listed. Zig build only.
      --prefix PREFIX, --prefix=PREFIX
          The install tree to check. Required; a newline in it is refused.
      --json
          Print one line of JSON instead.
      --require-none
          Exit 2 when any path under PREFIX was found.
      FILE
          One or more files of concatenated XALT JSON objects and/or Lmod
          ModuleUsageTracking lines. Required.
  eb-keep-logs usage --software DIR --modules DIR [--since EPOCH]
                     [--unused | --active] [--json] FILE...
      Compare installed DIR/Name/Version software with XALT and Lmod
      records. XALT paths below the software directory and Lmod module
      loads below the modules directory count as hits. By default, print
      every installed Name/Version with its state, hit count and newest
      time. --unused and --active print only Name/Version lines;
      --active output is accepted by eb-stack stack gap --site. --since
      ignores records older than EPOCH and records without a time.
      --json prints one JSON document with schema_version 1. Zig build
      only.
      --software DIR, --software=DIR
          The software install tree, with Name/Version directories.
          Required.
      --modules DIR, --modules=DIR
          The module tree that Lmod record paths must be below. Required.
      --since EPOCH, --since=EPOCH
          Count records at or after this non-negative epoch time.
          Default: all record times.
      --unused
          List installed Name/Version entries with no hit.
      --active
          List installed Name/Version entries with at least one hit.
      --json
          Print one line of JSON instead.
      FILE
          One or more files of concatenated XALT JSON objects and/or Lmod
          ModuleUsageTracking lines. Required.
  eb-keep-logs runs --exec PATH [--json] FILE
      Print who ran PATH, from XALT run records in FILE. A run record is a
      JSON object whose userT holds user, exec_path and, when present,
      syshost and start_time. A link record is not a run and is skipped.
      PATH matches exec_path in full or as its last component. Each run is
      one line, user=USER host=HOST time=TIME path=PATH, in the file's
      order. A file with no run of PATH prints no run of PATH. Zig build
      only. It does not record runs.
      --exec PATH, --exec=PATH
          The executable, as a full path or its last component. Required.
      --json
          Print one line of JSON instead, with schema_version 1.
      FILE
          One or more JSON objects. An object that is not a run record is
          skipped.
  eb-keep-logs pending [--json] FILE
      Print what an EasyBuild dry-run or missing-modules report still has
      to build. A dry-run line is "* [ ] PATH (module: NAME)", and [F] and
      [R] count as still to build; [x] is already installed and is not
      printed. --terse prints "x PATH" or "- PATH". A missing-modules line
      is "* NAME (FILE.eb)", or with --terse one easyconfig path on each
      line. Each is one line, build NAME or missing NAME, in the file's
      order. A report with nothing left prints nothing to build. Zig build
      only. It does not run eb, and it does not resolve dependencies.
      --json
          Print one line of JSON instead, with schema_version 1.
      FILE
          The report, as eb --dry-run or eb --missing-modules printed it.
          Required.
  eb-keep-logs test-bundle --test-id ID --suite-revision REV --eessi-target TARGET
                           ... --stdout FILE --stderr FILE [--input FILE ...]
                           ... [--module NAME=PATH ...] --seed SEED
                           ... --allocation TEXT --binding TEXT --cpu TEXT --gpu TEXT
                           [--out FILE]
      Write one flaky-test evidence bundle as JSON schema_version 1, with a
      stable test identity (ID), normalized stdout and stderr, input and
      seed hashes, full module list and module paths, EESSI target,

      revision. Without --out, print it on stdout. Zig build only.
      --test-id ID, --test-id=ID
          Stable test identity. Required.
      --suite-revision REV, --suite-revision=REV
          Test-suite revision. Required.
      --eessi-target TARGET, --eessi-target=TARGET
          EESSI target of the run. Required.
      --stdout FILE, --stdout=FILE
          Captured stdout, normalized and hashed. Required.
      --stderr FILE, --stderr=FILE
          Captured stderr, normalized and hashed. Required.
      --input FILE, --input=FILE
          Input file to hash. Optional; may be repeated. Default: none.
      --module NAME=PATH, --module=NAME=PATH
          Loaded module and its modulefile path. Optional; may be
          repeated. Default: none.
      --seed SEED, --seed=SEED
          Seed value to hash. Required.
      --allocation TEXT, --allocation=TEXT
          Scheduler allocation summary. Required.
      --binding TEXT, --binding=TEXT
          Scheduler binding summary. Required.
      --cpu TEXT, --cpu=TEXT
          CPU facts. Required.
      --gpu TEXT, --gpu=TEXT
          GPU facts, or none. Required.
      --out FILE, --out=FILE
          Write JSON to FILE. Default: stdout.
  eb-keep-logs test-compare [--json] BUNDLE...
      Summarize which evidence fields differ across two or more
      test-bundle JSON files, without deciding pass or fail. --json prints
      schema_version 1. Zig build only.
      --json
          Print one line of JSON instead of text. Default: text.
      BUNDLE
          Two or more test-bundle JSON files. Required.
  eb-keep-logs lifecycle --policy FILE [--modulerc-out FILE]
                         [--easyconfigs DIR ...] [--easystack FILE ...]
                         [--eb-stack PATH] [--rebuild-set FILE]
                         [--now EPOCH] [--json] FILE
      Generate a reversible lifecycle plan and Lmod .modulerc.lua
      warnings/forbids from usage --json output and a TOML policy. Never
      deletes software or modulefiles. Requires a minimum observation
      window and checks installed dependents via eb-stack rebuild-set
      before allowing candidate-remove. Zig build only.
      --policy FILE, --policy=FILE
          TOML lifecycle policy file. Required.
      --modulerc-out FILE, --modulerc-out=FILE
          Write the generated Lmod .modulerc.lua warnings and forbids
          durably to FILE. Default: none; no file is written.
      --easyconfigs DIR, --easyconfigs=DIR
          Easyconfig tree passed to eb-stack rebuild-set to identify
          dependents of candidate removals. Repeatable. Default: none.
      --easystack FILE, --easystack=FILE
          Deployed easystack YAML passed to eb-stack rebuild-set.
          Repeatable. Default: none.
      --eb-stack PATH, --eb-stack=PATH
          Path to the eb-stack executable. Default: eb-stack on PATH.
      --rebuild-set FILE, --rebuild-set=FILE
          Precomputed eb-stack rebuild-set.json report instead of
          running eb-stack. Default: none.
      --now EPOCH, --now=EPOCH
          Reference epoch time in seconds for idle age and observation
          window checks. Default: the environment time override, else
          the current time.
      --json
          Print one line of JSON instead, with schema_version 1.
      FILE
          JSON output produced by eb-keep-logs usage --json (with
          selection "all"). Required.

      Print this help on stdout and exit 0.
  eb-keep-logs --version
      Print the version line on stdout and exit 0.

  PATH                 Where failed looks up eb.
  EASYBUILD_TMPDIR     failed copies a command's output only from below it;
                       unset or empty, it copies none.
  EB_KEEP_LOGS_NOW     The time rotate and lifecycle take as now, in seconds
                       since the epoch; unset or empty, the current time.
  EB_PIPELINE_LOG_DIR  rotate leaves alone the run that holds this path.
  EB_KEEP_LOGS_SYSLOG  Default --syslog target (journald, syslog, unix:///...,

  EB_KEEP_LOGS_SYSLOG_PEN
                       IANA Private Enterprise Number for RFC 5424 SD-ID

      accepted its arguments, whatever it could keep, compress, remove or
