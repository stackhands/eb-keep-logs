* The eb-keep-logs command

=eb-keep-logs= keeps the logs of a failed EasyBuild build, compresses and removes the old runs of a log tree, says from the kept logs why a run's builds failed, lists how a package's builds went run by run, reads who loaded a module from Lmod's usage log, and reads who ran an executable from an XALT run record.
This page describes the Zig build; the shell script =eb-keep-logs= in the repository behaves the same, except as [[file:compatibility.org][Compatibility]] lists: it has no =why=, =history=, =loads= or =runs=.

** Synopsis

#+begin_example
eb-keep-logs failed [--syslog TARGET] STATUS NAME LOGDIR [TMP_LOGDIR]
eb-keep-logs rotate ROOT --compress-after DAYS [--delete-after DAYS] [--lock-timeout SECONDS] [--syslog TARGET]
eb-keep-logs why [RUN | --latest] [--target TARGET] [--root ROOT] [--json]
eb-keep-logs history PACKAGE [--target TARGET] [--root ROOT] [--json]
eb-keep-logs loads --module NAME FILE
eb-keep-logs runs --exec PATH FILE
eb-keep-logs -h | --help
eb-keep-logs --version
#+end_example

** Arguments

| Argument     | Command  | Meaning                                                                                                                                                                                                 |
|--------------+----------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =STATUS=     | =failed= | The exit status =eb= returned, in decimal digits. A status of only zeros keeps and changes nothing, once =LOGDIR= has been checked.                                                                     |
| =NAME=       | =failed= | The easyconfig's name without =.eb=, as in =LOGDIR/NAME.stdout.log=; it names the copies, and without =TMP_LOGDIR= it tells the build's own log from another build's.                                   |
| =LOGDIR=     | =failed= | The run's directory, which holds =NAME.stdout.log= and gets the copies and =.licensed-logs=; a symbolic link to a directory is followed.                                                                |
| =TMP_LOGDIR= | =failed= | The =--tmp-logdir= =eb= ran with, passed on to =eb --last-log=. Empty is the same as not given: =eb --last-log= then names the newest log in EasyBuild's default place. Arguments after it are ignored. |
| =ROOT=       | =rotate= | The directory that holds the runs. A run is a directory directly under it, not a symbolic link, named =YYYYMMDD_HHMMSS= with a date that exists; everything else under it is left alone.                |
| =RUN=        | =why=    | The run to read: a path, or a name under =--root=. Its builds are in it, as =failed= given it as =LOGDIR= keeps them, or in its directories, one per target, not symbolic links, as eb-pipeline keeps them. |
| =PACKAGE=    | =history= | An easyconfig's name, or its start up to a dash: =hello= and =hello-2.12.1= both take =hello-2.12.1-GCCcore-14.2.0=, and =hello= takes =hello-world-1.0= too. A module name, =hello/2.12.1=, is read as =hello-2.12.1=. |

** Options

| Option                                           | Command  | Meaning                                                                                                                                      |
|--------------------------------------------------+----------+----------------------------------------------------------------------------------------------------------------------------------------------|
| =--compress-after DAYS=, =--compress-after=DAYS= | =rotate= | Required. Compress the =*.log= and =*.txt= files, at any depth, of runs at least =DAYS= old. =DAYS= is decimal digits.                       |
| =--delete-after DAYS=, =--delete-after=DAYS=     | =rotate= | Remove whole runs at least =DAYS= old. =DAYS= must be larger than =--compress-after=. Without it, or with an empty value, no run is removed. |
| =--lock-timeout SECONDS=, =--lock-timeout=SECONDS= | =rotate= | How long to wait for the lock another =rotate= of =ROOT= holds, in seconds, decimal digits; =0= does not wait. Without it, or with an empty value, 600. A value larger than 999999999, which is over 31 years, waits 999999999 seconds. |
| =--syslog TARGET=, =--syslog=TARGET=             | =failed=, =rotate= | Emit an RFC 5424 or native =systemd-journald= event to =TARGET= (=journald=, =syslog=, =unix:///path=, =journal+unix:///path=, =udp://host:port=, or =tcp://host:port=); overrides =EB_KEEP_LOGS_SYSLOG=. An empty value disables emission. |
| =--latest=                                       | =why=    | Read the newest run under =--root=, by its name; with =--target=, the newest that has that target. The default without =RUN=.               |
| =--target TARGET=, =--target=TARGET=             | =why=, =history= | Read only the builds in the run's directory =TARGET=; for =history=, in each run's, a run without one passed over. Without it, those in the run's own directory and then in each directory in it, by name. |
| =--root ROOT=, =--root=ROOT=                     | =why=, =history= | The directory that holds the runs, directories named =YYYYMMDD_HHMMSS=, not symbolic links. Without it, the current directory.               |
| =--json=                                         | =why=, =history= | Print one line of JSON instead of the report; its keys are under Files below.                                                                |
| =-h=, =--help=                                   |          | Print the usage on stdout and exit 0.                                                                                                        |
| =--version=                                      |          | Print the version line on stdout and exit 0.                                                                                                 |

- A run's age is the number of whole days from the local midnight of the date in its name; [[file:../explanation/local-time.org][Run ages and local time]] gives the details.
- =rotate='s options and =ROOT= come in any order; the value of an option is the next argument, whatever it is.
  An option given twice takes its last value.
- =why='s options and =RUN=, and =history='s and =PACKAGE=, come in any order, and an option given twice takes its last value; the value of an option is the next argument, whatever it is, and an empty one is refused.
- =-h=, =--help= and =--version= count only in the place of the command.
- =failed= takes no options.

** Files

*** failed

| File                                             | Use                                                                                                                                                                                                      |
|--------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =LOGDIR/NAME.stdout.log=                         | Read: the last =.../run-shell-cmd-output/DIR/out.txt= path in it names the failed command's output. Closed to others, not through a symbolic link.                                                       |
| the session log =eb --last-log= names            | Read, and copied to =LOGDIR/NAME.failed.ebout.log=. When =NAME.stdout.log= names no =out.txt=, the last one the session log names is taken, unless the log records that command completing successfully. |
| =LOGDIR/NAME.failed.ebout.log=                   | The session log.                                                                                                                                                                                         |
| =LOGDIR/NAME.failed.command-out.txt=, =-err.txt= | The failed command's =out.txt= and, when there is one, =err.txt=, mode 0600. A stream that is a symbolic link is not opened.                                                                             |
| =LOGDIR/NAME.failed.meson-testlog.txt=           | =meson-logs/testlog.txt= of the last =meson test -C DIR= the session log names, unless every test in it passed.                                                                                          |
| =LOGDIR/.licensed-logs=                          | Each copy's absolute path, with symbolic links resolved, is appended unless the list has it.                                                                                                             |
| =TMP_LOGDIR=                                     | Closed to others, with the regular files directly in it, when it lies below =LOGDIR=.                                                                                                                    |

Each copy is written to a temporary file in =LOGDIR= and renamed over the name, so a copy that fails part way leaves an earlier one as it was.
A copy takes the source's mode, or the mode and, when permitted, the owner of the file it replaces, without others' bits; the command's streams are mode 0600.
A symbolic link, a directory or another file that is not a regular one at a copy's name is not written through: the copy is refused, with =eb-keep-logs: cannot keep LOGDIR/FILE: ERROR= on stderr.

| Line                                                                  | When                                                                                                                       |
|-----------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------|
| =Failed build log: LOGDIR/NAME.failed.ebout.log=                      | The session log was kept.                                                                                                  |
| =Failed command output: LOGDIR/NAME.failed.command-out.txt=           | A command stream was kept, one line for each.                                                                              |
| =Failed meson test log: LOGDIR/NAME.failed.meson-testlog.txt=         | The meson test log was kept.                                                                                               |
| =No EasyBuild log to keep for NAME: eb is not on PATH.=               | =eb= is not on =PATH=; nothing is kept.                                                                                    |
| =No EasyBuild log to keep for NAME: eb --last-log exited N.=          | =eb --last-log= failed; nothing is kept.                                                                                   |
| =No EasyBuild log to keep for NAME.=                                  | =eb --last-log= printed nothing, named no log that could be opened, or did not return within 300 seconds; nothing is kept. |
| =No EasyBuild log to keep for NAME: PATH is another build's log.=     | Without =TMP_LOGDIR=, the newest log is another build's; the command output =NAME.stdout.log= names is still kept.         |
| =Failed command output not kept: EASYBUILD_TMPDIR is not set.=        | =EASYBUILD_TMPDIR= is unset or empty.                                                                                      |
| =Failed command output not kept: PATH is not under EASYBUILD_TMPDIR.= | The stream lies elsewhere.                                                                                                 |
| =Failed command output not kept: PATH belongs to another user.=       | The stream is not the caller's.                                                                                            |

| =cannot stat PATH: ERROR=                   | A copy, =NAME.stdout.log=, =TMP_LOGDIR= or a file in it could not be examined; it is not closed to others.                                                                                                                                                                     |
| =cannot close PATH to others: ERROR=        | Its mode could not be changed.                                                                                                                                                                                                                                                 |
| =cannot resolve a kept file: ERROR=         | A copy's absolute path could not be found; it is not listed.                                                                                                                                                                                                                   |
| =cannot list PATH in .licensed-logs: ERROR= | The line could not be appended to =.licensed-logs=.                                                                                                                                                                                                                            |

Such a session log is still copied, but nothing is taken from it; for such a =NAME.stdout.log=, the session log is searched instead; such a meson test log is still kept. |

*** rotate

| File                                | Use                                                                                                                                                                                                                                                     |
|-------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =ROOT/.eb-keep-logs-rotate.lock=    | Created empty when missing, and left in place. =rotate= holds an exclusive flock(2) lock on it from before it lists =ROOT= until it exits, and opens it for reading when it may not write it. eb-pipeline's =ROOT/.eb-pipeline-rotate.lock= is another lock, which =rotate= does not take. |
| =ROOT/RUN/.../FILE.log=, =FILE.txt= | In a run old enough, replaced by =FILE.gz= with the file's mode, as =gzip -9= does; a symbolic link is not followed, and a file with other hard links or an existing =FILE.gz= is left as it is, with a message on stderr.                              |
| =ROOT/RUN/.../.licensed-logs=       | In a run in which files were compressed, a line that names one of them, by its absolute path with symbolic links resolved, is changed to name its =.gz= file. A list that changes keeps its owner when permitted, its mode and its access control list. It is replaced whole: the new list is written to a file beside it, synced and renamed over it, and the directory is synced, so a reader finds the old list or the new one, never part of one. |
| =ROOT/RUN=                          | Removed with everything in it, when old enough for =--delete-after=, without being compressed first. A symbolic link in it is removed, not followed. Removal stops at the first error.                                                                  |
| =/proc/PID/fd/N=                    | Read, for every process whose descriptors =rotate= may read, after it has the lock: a link with its owner's write bit names a file the process has open for writing, and the run that file is in is left alone. Without =/proc=, no run is left alone for it. |

A run that holds the file =rotate='s standard output or standard error goes to, or =EB_PIPELINE_LOG_DIR=, or a file another process has open for writing, as a build that is still going has its log, is left alone, neither compressed nor deleted; a later =rotate= takes it.
The path is what counts: the path the link in =/proc= names, or for a file removed since, that path with =" (deleted)"= after it, has to start with =ROOT='s, with symbolic links resolved.
On stdout =rotate= prints one line, with =ROOT= as given:

#+begin_example
eb-keep-logs rotate: N files compressed, M runs deleted under ROOT
#+end_example

with =1 file= and =1 run= for a count of one.
What =rotate= cannot do it reports on stderr as =eb-keep-logs: MESSAGE=, and goes on with the rest; a file or run it reports is not counted:

| =MESSAGE=                               | Cause                                                                                                                               |
|-----------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------|
| =cannot lock ROOT/.eb-keep-logs-rotate.lock: ERROR; rotating without the lock= | The file system cannot take the lock, or not for this user: =Unsupported= where it takes no locks, =InvalidArgument= on NFS for a lock file open only for reading, =Unexpected= when no lock is available (=ENOLCK=). =rotate= goes on without it. |
| =cannot compress PATH: ERROR=           | =PATH= is left as it is: it has other hard links (=TooManyLinks=), =PATH.gz= exists (=Exists=), or it could not be read or written. |
| =cannot open PATH: ERROR=               | A run, or a directory in a run, could not be opened; nothing in it is compressed.                                                   |
| =cannot read PATH: ERROR=               | Listing a run, or a directory in it, failed part way; nothing in it is compressed.                                                  |
| =cannot resolve a run directory: ERROR= | The absolute path of a run, or of a directory in it, could not be found; nothing in it is compressed.                               |
| =cannot read a .licensed-logs: ERROR=   | A list could not be read, or is larger than 64 MiB; it is left as it is.                                                            |
| =cannot update a .licensed-logs: ERROR= | A list could not be replaced; it is left as it is.                                                                                  |
| =cannot sync a .licensed-logs: ERROR=   | A list was replaced, but its directory could not be synced; after a crash the old list may be back.                                 |
| =cannot delete ROOT/RUN: ERROR=         | The run could not be removed completely; what was removed stays removed.                                                            |

*** why

=why= only reads.
A build is a =NAME= with either of its logs in the run's own directory or in one of its target directories; of =FILE= and =FILE.gz=, =FILE= is read, and a =.gz= file is read through gzip, its CRC-32 checked.

| File                                        | Use                                                                                                                                                                                                                                              |
|---------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =RUN/[TARGET/]NAME.stdout.log=, =.gz=       | EasyBuild's output, which says how the build went: the last =COMPLETED: Installation ended successfully= or =FAILED: Installation ended unsuccessfully= in it decides, with the duration in it; an =ERROR:= line after a success, or without either, is a failure. |
| =RUN/[TARGET/]NAME.failed.ebout.log=, =.gz= | The session log =failed= kept, which says why the build failed. A build whose output says nothing of how it went has failed when this log is there; without either, its outcome is unknown.                                                    |

What =why= takes from a failed build's session log, or from its output when it has none:

| Item       | Taken from                                                                                                                                                                                                                                                                                                                                                         |
|------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| package    | EasyBuild's =building and installing NAME/VERSION...=.                                                                                                                                                                                                                                                                                                              |
| easyconfig | EasyBuild's =processing EasyBuild easyconfig PATH=.                                                                                                                                                                                                                                                                                                                 |
| message    | EasyBuild's message for the failure: =EasyBuild encountered an error: MESSAGE= in the session log; in the output, the =FAILED: Installation ended unsuccessfully: MESSAGE= entry with EasyBuild's wrapping at 80 columns undone, or else the first =ERROR: MESSAGE=. Its first 400 bytes.                                                                    |
| step       | The step the =FAILED= entry names, as in =... failed with exit code 2 in build step for NAME.eb=; else the last step the log shows starting before the failure: =Starting STEP step= in the session log, an announcement such as ~== sanity checking...~ in the output. By EasyBuild's name, as =eb --stop= takes it: =fetch=, =ready=, =extract=, =patch=, =prepare=, =configure=, =build=, =test=, =install=, =extensions=, =postiter=, =postproc=, =sanitycheck=, =cleanup=, =module=, =permissions=, =package=, =testcases=. None when the failure came before the first step, as a missing dependency does. |
| error      | The line that shows the error: the first compiler or linker error from the start of that step to EasyBuild's own error line, else that line. A compiler's error is one at a source line, =FILE:LINE: error:= or =FILE:LINE:COLUMN: fatal error:= as GCC and Clang print it, or =FILE(LINE): error:= as nvcc does; a linker's is =undefined reference to= or =cannot find -l= as GNU ld prints them, or =undefined symbol:= as lld and mold do. EasyBuild's own error line is its first =EasyBuild encountered an error= in the session log; in the output, the =FAILED= entry, or else the first =ERROR:=. In a session log, nothing before the first step counts. With its line number and three lines either side, each cut to 400 bytes. |
| duration   | The =(took DURATION)= of the =FAILED= entry, in seconds.                                                                                                                                                                                                                                                                                                         |

For a failure class, feed the kept log to [[https://eb-stack.rgoswami.me/][eb-stack]]; =why= gives none.

| =step=           | The step.                                                                                                                     |
| =message=        | EasyBuild's message.                                                                                                          |
| =duration_s=     | The duration in seconds, from the =FAILED= entry or else from EasyBuild's output.                                             |
| =log=            | The path of the log read: =run_dir/TARGET/FILE=, or =run_dir/FILE=.                                                           |
| =error=          | ={"line": N, "text": LINE, "before": [LINE, ...], "after": [LINE, ...]}=, the error line and its context, or =null=.          |

Text in the JSON is UTF-8: a byte of a log that is not part of a UTF-8 character is U+FFFD.
What =why= cannot read it reports on stderr as =eb-keep-logs: MESSAGE=, and goes on with the rest:

| =MESSAGE=                  | Cause                                                                                                                                              |
|----------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------|
| =cannot open PATH: ERROR=  | A target directory could not be opened; its builds are not read.                                                                                   |
| =cannot read PATH: ERROR=  | A target directory could not be listed, or a log could not be read: =BadGzip= for a =.gz= that is not gzip or is damaged, =StreamTooLong= for one of 1 GiB or more. A failed build whose log it is, is still listed. |

*** history

=history= only reads, the same files as =why=: in each run under =ROOT=, oldest first, in the run's own directory and then in each of its target directories, by name, the builds whose =NAME= is =PACKAGE= or starts with =PACKAGE= and a dash.
A build's outcome and duration come from its output, =NAME.stdout.log=, as =why= reads them; its session log is not read, and tells only that the build failed when its output does not say.
The report on stdout counts the builds by outcome and lists them, a build in the run's own directory with the target =-=, and a duration EasyBuild did not print as =-=:

#+begin_example
hello-2.12.1-GCCcore-13.3.0: 2 builds under tests/fixtures/build-logs: 1 succeeded, 1 failed

RUN              TARGET          OUTCOME  DURATION  NAME
20261117_041222  sapphirerapids  failed   2m54s     hello-2.12.1-GCCcore-13.3.0
20261117_042207  sapphirerapids  success  2m40s     hello-2.12.1-GCCcore-13.3.0
#+end_example

The first line ends with =, N unknown= when an outcome is unknown; with no build found, it is =PACKAGE: 0 builds under ROOT= alone.
With =--json=, =history= prints one line of JSON instead, its keys in this order:

| Key              | Value                                                                                                  |
|------------------+--------------------------------------------------------------------------------------------------------|
| =schema_version= | =1=, versioned as =why='s is.                                                                          |
| =kind=           | ="history"=.                                                                                           |
| =package=        | =PACKAGE= as given.                                                                                    |
| =root=           | =ROOT= as given, =.= without =--root=.                                                                 |
| =counts=         | ={"success": N, "failed": N, "unknown": N}=, the builds found, by outcome.                             |
| =builds=         | One object for each build, in the order of the report.                                                 |

| Key in a build   | Value                                                                                                  |
|------------------+--------------------------------------------------------------------------------------------------------|
| =run=            | The run's name.                                                                                        |
| =target=         | The target directory, or =null= for a build in the run's own directory.                                |
| =name=           | =NAME=.                                                                                                |
| =outcome=        | ="success"=, ="failed"= or ="unknown"=.                                                                |
| =duration_s=     | The duration in seconds EasyBuild printed, or =null=.                                                  |
| =log=            | The log read: =ROOT/RUN/[TARGET/]NAME.stdout.log= or its =.gz=, or the session log when there is no output. |

What =history= cannot read it reports on stderr as =why= does, a run that cannot be opened with =cannot open PATH: ERROR= too, and goes on with the rest; a build whose output could not be read is still listed.

** loads

=loads --module NAME FILE= prints who loaded =NAME=, from Lmod's ModuleUsageTracking lines in =FILE=.
A record is =user=USER module=NAME path=PATH host=HOST time=TIME=, in any order, with a syslog prefix left in place.
Each load is one line, =user=USER host=HOST time=TIME path=PATH=, in the file's order.
A file with no load of =NAME= prints =no load of NAME=.
A line that is not a record is skipped.
The shell script has no =loads=.

| Argument | Meaning |
|---|---|
| =NAME= | The module's full name, as Lmod recorded it, such as =GROMACS/2024.1=. Required, as =--module NAME= or =--module=NAME=. |
| =FILE= | The log. A file that cannot be read is refused. |


** runs

=runs --exec PATH FILE= prints who ran =PATH=, from XALT run records in =FILE=.
A run record is a JSON object whose =userT= holds =user=, =exec_path= and, when present, =syshost= and =start_time=.
A link record is not a run and is skipped.
=PATH= matches =exec_path= in full or as its last component.
Each run is one line, =user=USER host=HOST time=TIME path=PATH=, in the file's order.
A file with no run of =PATH= prints =no run of PATH=.
The shell script has no =runs=. It does not record runs.

| Argument | Meaning |
|---|---|
| =PATH= | The executable, as a full path or its last component. Required, as =--exec PATH= or =--exec=PATH=. |
| =FILE= | One or more JSON objects. An object that is not a run record is skipped. A file that cannot be read, or that is not JSON, is refused. |
