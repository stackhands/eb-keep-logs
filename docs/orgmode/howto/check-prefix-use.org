* Check whether a prefix is still in use

Before uninstalling or retiring an install tree, see whether XALT or Lmod records still name paths under it.
=runs= answers who ran one executable and skips link records; =loads= answers who loaded one module by name.
=used= scans every record kind and aggregates by path. It does not record use, and it does not open a database.

** Before starting

- The Zig build of =eb-keep-logs=. The shell script answers =used= with =used is in the Zig build only=.
- Files of XALT JSON objects and/or Lmod ModuleUsageTracking lines, as the site already keeps.
  Run records carry =userT= and optionally =libA=. Link records carry =resultT= and =linkA=.
  Package records carry =package_path=. Lmod lines carry =path= under the module tree.

** Steps

1. Pass the install prefix and the record files:

   #+begin_src bash
   eb-keep-logs used --prefix /opt/site/software/pkg-1.0 /var/log/xalt.json /var/log/moduleUsage.log
   #+end_src

   Each hit is one line, =path=PATH kind=KIND last=TIME count=N=.
   =last= is the newest time seen for that path; it may be empty when no time was recorded.
   No path under the prefix prints =nothing under /opt/site/software/pkg-1.0=.

2. To gate uninstall or retire on zero use:

   #+begin_src bash
   eb-keep-logs used --prefix /opt/site/software/pkg-1.0 /var/log/xalt.json --require-none
   #+end_src

   Exit status 2 means at least one path was listed; 0 means nothing under the prefix.

3. For machine output:

   #+begin_src bash
   eb-keep-logs used --prefix /opt/site/software/pkg-1.0 --json /var/log/xalt.json
   #+end_src

** If it fails

| Message | Cause | What to do |
|---|---|---|
| =eb-keep-logs: used is in the Zig build only= | The =eb-keep-logs= on =PATH= is the shell script. | Put the Zig build first on =PATH=. |
| =eb-keep-logs: used needs --prefix= | =--prefix= was omitted or empty. | Pass the install tree to check. |
| =eb-keep-logs: used needs a record file= | No file was given. | Pass at least one record file. |
| =eb-keep-logs: used: PATH is not XALT run JSON= | A file held truncated or invalid JSON. | Fix the file; partial hits from a bad object are not printed. |
| =eb-keep-logs: used does not know 'OPTION'= | An option other than those listed. | Drop it. |
