* See who loaded a module

Read Lmod's module-usage log before retiring a module, and see who loaded it.
Lmod can syslog each load as =user=USER module=NAME path=PATH host=HOST time=TIME= with the tag =ModuleUsageTracking=, as [[https://lmod.readthedocs.io/en/latest/300_tracking_module_usage.html][Tracking Module Usage]] describes.
=eb-keep-logs loads= reads that log. It does not record loads, and it does not retire the module.

** Before you start

- =eb-keep-logs= 0.2.0 or later. The shell script 0.1.0 answers =loads= with =loads is in the Zig build only=.
  Put the Zig build first on =PATH=, as [[file:find-why-a-build-failed.org][Find why a build failed]] does for =why=.
- A file of tracking lines. A syslog prefix in front of the record is fine. =journalctl= output redirected to a file is one.

** Steps

1. Ask for the module's full name, the =module== field Lmod recorded:

   #+begin_src bash
   eb-keep-logs loads --module GROMACS/2024.1 /var/log/moduleUsage.log
   #+end_src

   Each load is one line, in the file's order:

   #+begin_example
   user=alice host=login01 time=1731840001.250000 path=/cvmfs/g.lua
   #+end_example

   =time== is the epoch Lmod wrote. A recent time is someone who still loads the module.

2. A log that never mentions the module prints one line and exits 0:

   #+begin_example
   no load of GROMACS/2024.1
   #+end_example

   That is the point at which a retirement has no recorded load to weigh. =eb-staged-rebuild retire= still does not read this log; you do, and then you retire.

** If it fails

| Message | Cause | What to do |
|---|---|---|
| =eb-keep-logs: loads is in the Zig build only= | The =eb-keep-logs= on =PATH= is the shell script 0.1.0. | Put the Zig build first on =PATH=. |
| =eb-keep-logs: loads needs --module= | =--module= was omitted, or its value was empty. | Pass the full module name, as =GROMACS/2024.1=. |
| =eb-keep-logs: loads needs a log file= | No file was given. | Pass the path of the tracking log. |
| =eb-keep-logs: cannot read FILE: ERROR= | The file cannot be opened or is larger than 64 MiB. | Point at the log you can read, or split a larger one. |
| =eb-keep-logs: loads does not know 'OPTION'= | An option other than =--module=. | Drop it. The command takes =--module= and one file. |
