`loads`, `used`, `usage`, and `pending` replace a byte that is not valid UTF-8 with the Unicode replacement character before printing it, as `why` already did, whether the byte came from a module name or a path in a record or from a value given on the command line and printed back: `loads --module`, `used --prefix`, `usage --software` and `--modules`, `runs --exec`, and the `--policy` path in `lifecycle --json`. Neither the plain report nor the `--json` field for that value carries a raw invalid byte or changes type.
