COMPAT.md lists three differences between the Zig build and the shell script that are bugs, not choices: an empty `EB_KEEP_LOGS_NOW` is refused instead of meaning the current time, an empty `TZDIR` leaves a zone name relative to the working directory, and a `TZ` with a leading `:` that names no file is UTC. Its rows on `EB_KEEP_LOGS_NOW` and on run ages no longer claim more than the Zig build does.
